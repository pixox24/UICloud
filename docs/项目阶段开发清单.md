# 项目阶段开发清单

## 项目简介

本项目是一个基于 Next.js 14、SQLite 和本地文件存储构建的设计资产库，主要面向团队内部在局域网环境中统一上传、分类、筛选、预览、收藏和下载 UI 设计资源，同时兼顾 Windows 本地部署、后台自启动、自动缩略图生成和日常备份运维。
