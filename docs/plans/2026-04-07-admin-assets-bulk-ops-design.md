# 资产管理页批量操作与缩略图状态设计

日期：2026-04-07

## 目标

- 在资产管理页增加“缩略图”字段。
- 支持当前页多选。
- 支持当前页已选资产的批量上架、批量下架、批量删除。

## 设计

- 列表最左侧增加复选框列。
- 表头提供“全选当前页”复选框。
- 当存在选中项时，在表格上方显示批量操作条。
- “缩略图”字段使用简洁图标显示：
  - 有缩略图：勾
  - 无缩略图：叉

## 数据逻辑

- 缩略图状态不新增数据库字段，直接依据现有缩略图路径判断：
  - `thumbnail_medium`
  - `thumbnail_path`
  - `thumbnail_original`
  - `thumbnail_large`
  - `thumbnail_small`
- 只要以上任意一个有值，即视为“有缩略图”。

## 接口策略

- 继续复用 `/api/assets`。
- `PUT` 扩展支持：
  - `ids: number[]`
  - `is_active: 0 | 1`
- `DELETE` 扩展支持：
  - `ids: number[]`

## 范围边界

- 第一版只支持“当前页”选择，不做跨页选择。
- 第一版不做批量改分类、批量改标签、批量重命名。
