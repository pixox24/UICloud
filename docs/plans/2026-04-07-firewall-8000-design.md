# Windows 防火墙 8000 端口配置

日期：2026-04-07

## 目标

- 让局域网内其他电脑可以访问 `http://内网IP:8000`
- 避免手动去防火墙界面点规则
- 和现有 `setup-startup.bat` 串起来，一次完成自启动与防火墙配置

## 方案

- 新增 `setup-firewall.bat`
- 规则名固定为 `UI Library Port 8000`
- 每次执行时先删除同名旧规则，再创建新规则，避免重复

## 规则内容

- 方向：入站
- 动作：允许
- 协议：TCP
- 端口：`8000`
- 配置文件：`Private,Domain`
- 来源地址：`LocalSubnet`

## 取舍

- 不开放 `Public` 配置文件，避免公共网络下误暴露
- 使用 `LocalSubnet`，只允许本地局域网访问，安全性更高
