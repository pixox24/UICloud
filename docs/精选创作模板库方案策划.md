# 精选创作模板库方案策划

**目标**：将 AI 生成的结果（prompt + 输出）保存为可复用模板，存入“精选创作模板库”，支持搜索、分类、导入导出、版本管理等功能。目标上线后可直接用于日常创作复用。

## 1. 方案概述
- **核心功能**：
  - 用户输入 prompt → AI 生成结果 → 一键保存为模板。
  - 模板库：精选模板（Featured）、我的模板（My Templates）、草稿箱。
  - 模板属性：prompt 原文、生成结果（文本/图片/代码）、标签（领域：代码、设计、营销、产品等）、难度/质量评分、预览图、创建时间。
  - 库内搜索：按关键词、标签、领域、质量过滤。
  - 导入/导出：JSON 格式，支持批量导入本地模板。
  - 分享：生成分享链接或导出为 Markdown/Zip。

- **存储方案**：
  - 本地文件存储（推荐）：`~/.opencode/templates/` 或 `C:\Users\...\opencode\templates\`。
  - JSON 文件结构：`{ "id": "uuid", "prompt": "...", "result": "...", "tags": ["code", "ui"], "created": "2026-...", "preview": "base64 or path" }`
  - 备选：SQLite 本地数据库（轻量）。
  - 版本控制：模板可 fork/branch，保留历史版本。

- **集成方式**：
  - 嵌入到现有 prompt 历史记录面板或 AI 对话界面。
  - CLI 命令：`opencode save-template`、`opencode list-templates`。

## 2. 详细用户体验（User Journey）
1. **创作阶段**：
   - 用户在对话中输入 prompt，获得生成结果。
   - 界面显示“保存为模板”按钮（可选：自动保存高质量结果）。

2. **保存流程**：
   - 点击按钮 → 填写元数据：模板名称、标签（多选）、描述、是否精选。
   - 确认后保存至库。
   - 成功后跳转到模板库列表页，预览缩略图+prompt 片段。

3. **使用模板**：
   - 在任何新对话中，点击模板卡片 → 自动填充 prompt 到输入框。
   - 支持“一键复用”：直接复制 prompt 或一键生成。

4. **库管理页**：
   - 左侧：标签过滤器（云朵标签）。
   - 中间：网格/列表视图（支持搜索框）。
   - 右侧：模板详情页（prompt 全文本、结果、编辑/删除/导出/分享）。
   - 顶部：排序（最新/质量）、导入按钮。

5. **移动端友好**（可选）：
   - 底部导航栏：创作 → 模板库 → 我的 → 设置。

6. **完成动作**：
   - 保存后通知“模板已保存，可在库中查看”。
   - 首次使用提示：引导用户发现模板库功能。

## 3. 注意事项与风险控制
- **数据安全**：本地存储，避免云端上传敏感 prompt，避免泄露代码/IP。
- **权限**：模板库仅本地用户可见；精选模板需管理员审核（可选）。
- **性能**：模板库过大时（>1000 个），实现分页 + 懒加载；支持搜索索引（Algolia 客户端或简单 grep）。
- **兼容性**：
  - 支持多种结果类型：纯文本、Markdown、代码块、图片 base64/URL。
  - 图片模板：保存缩略图 + 原始链接。
- **错误处理**：
  - 保存失败（磁盘满、JSON 解析错）→ 提示“保存失败，请检查空间”。
  - 冲突模板名 → 自动加后缀（如 “模板名 (1)”）。
  - 导入时验证 JSON 格式。
- **合规**：符合本地化存储政策；无网络请求（除可选分享）。
- **测试场景**：
  - 空模板、重复保存、导出大量模板、不同结果类型混合。
